### 🔧 Quick Start

#### Local Development
```bash
# Clone the repository
git clone https://github.com/MillionthOdin16/Pfd.git
cd Pfd

# Option 1: Open directly in browser (may have CORS issues)
open index.html

# Option 2: Use Python server
python3 -m http.server 8000

# Option 3: Use Node.js
npx serve

# Option 4: Use npm script
npm start
```

#### Enable Demo Mode
Edit `app.js` line 4:
```javascript
const DEMO_MODE = true;  // Change from false to true
```
